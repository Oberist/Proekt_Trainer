НАЗНАЧЕНИЕ ПАПОК -
.vscode - внутренние папки vscode, в них определяются пути к файлам,библиотекам, а также инструкции для сборки проекта.Для нашего проекта не прям нужны,но в некоторых случаях помогают.

DAO - В Каждой из подпапок DAO обязательно находятся два файла - .h и .cpp . Вместе,они представляют слой доступа для работы с таблицой РЕЛЯЦИОННОЙ базы данных.(то есть например подпапка Exercise отвечает за удобное взятие,дополнение данных из таблицы Exercise).

Database - в ней находятся сама реляционная база данных . Файлы с расширением .sql - это просто запросы sql.Сами они ничего не хранят,но создают таблицы в базе данных.  Файлы с расширением .db - это сами базы данных. TrainingDiary.db - Это основная база данных.
TrainingDiaryVector.db - это промежуточная между векторной и реляционной. В папке images понятно - изображения для упражнений (именно к файлам из нее указываем путь) .В папке import - файл с текстовым файлом.
Используя его, ExerciseAdding.cpp берет информацию,и сама кидает в таблицу.

Libs - папка с необходимыми библиотеками для работы.

Managers - в каждой подпапке находится реализация одного менеджера,аналогично с DAO (то есть .h файл + .cpp). Менеджеры управляют самой логикой приложения,как оно управляет данными и тд.

Models - папка в которую я предлагаю загрузит модель,также в ней находится python файл с embedding.

VectorData - Папка с реализацией векторной базы данных. Важное уточнение - в ней есть отдельная база данных на данный момент,но это чисто для тестов - впоследствии следует чтобы вся информация была в Database. Файлы embedding.cpp и embedding.h переводят 
embedding из питона к C++ файлам. VectorDAO работает с самой базой данных. Также реализован тест векторной бд в папке.

СЛОВАРЬ РАСШИРЕНИЙ ФАЙЛОВ 
.h .dll .a .def - библиотеки
.o - обьектный файл.Создается при компиляции,Упрощает ее

.exe - исполняемы файл. Для запуска просто введите команду ./имя_файла в терминал (важно,лучше делать это в подпапке с файлом)

.sql - файлы sql запросов

.db - базы данных

.bin - место хранения векторов.
